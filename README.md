# vitePlay

🚀 A lightning-fast playground powered by [Vite](https://vitejs.dev/).

## Features
- ⚡ Instant server start
- 🛠️ Optimized builds
- 📦 Out-of-the-box support for TypeScript, JSX, CSS

## Quick Start
```bash
# Clone the repo
 git clone https://github.com/EdenMD/vitePlay.git
 cd vitePlay

# Install dependencies
 npm install

# Start dev server
 npm run dev
```

## Scripts
- `npm run dev` - Start development server
- `npm run build` - Production build
- `npm run preview` - Preview production build
